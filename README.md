# 题衡 PaperCompile

面向高校课程组的「教学大纲 → 可审查试卷」命题编译 MVP：把大纲解析、知识点审定、蓝图、契约、多 Agent 出题审题、教师终审、成卷导出与过程回放串成一条可检查、可追溯、可复现的流水线。

> 纯前端 Vite + React + TypeScript + Zustand，无后端、无数据库、不接入真实 LLM。目标：`npm install && npm run dev` 后十分钟内复现完整七步闭环。

## 本次优化说明

本次只做 **界面精简 + 多学科通用化 + 页面职责梳理**，未改动项目主线：

- 保留编译式命题思想（大纲视为源程序，知识点 / 蓝图 / 契约是可检查的中间表示）。
- 保留七步命题闭环、6 个 Agent、七道校验闸门、L1~L7 七层溯源链。
- 保留命题蓝图、命题契约、试卷状态机（草稿 → 待审 → 已审 → 已签发 → 已归档单向流转）。
- 保留教师终审决策权与「不自动定稿」产品规则。

具体改动：

1. **页面说明卡**：八个主页面顶部统一显示「本页目标 / 第 X 步（共 7 步）/ 下一步操作提示 / 当前课程」。
2. **七步进度条**：顶部新增可视化进度条，已完成、当前、未开始三种状态；侧栏导航显示每个页面所在的闭环步骤与职责。
3. **尺寸修复**：表格单元格、文本域、滚动容器增加最小高度，滚动区默认至少可见 3~5 行；长文本自动换行，蓝图矩阵输入框加大。
4. **降噪折叠**：命题运行记录、命题说明、版本快照等次要信息默认折叠；核心证据（契约、闸门结论、溯源链）不折叠。
5. **多课程解耦**：课程名称、章节、学时、知识点、题型、分值、题量、难度目标、覆盖率阈值、配比带宽全部改为课程模板配置，不再写死《数据结构》。
6. **课程入口**：侧栏「当前课程」可打开课程选择 / 新建弹窗；内置《数据结构》《操作系统》《计算机网络》三个模板，支持新建自定义课程。
7. **页面职责单一化**：每页只做一件事（见下表），不再把生成、审查、导出混在同一屏。

## 启动

> **不要直接双击 `index.html` 或 `dist/index.html`。** 这不是静态单文件页面，浏览器以 `file://` 打开时无法加载 Vite 的 TypeScript / React 模块，会显示空白。必须通过本地 HTTP 服务打开。

### 手动启动

```bash
cd papercompile
npm install
npm run dev
```

终端会输出地址，浏览器打开：

```text
http://localhost:5173/
```

根路径会自动跳转到 `/outline`。若 5173 被占用，Vite 会换端口，以终端实际输出为准。也可以直接：

```bash
npm run dev -- --open
```

### Windows 一键启动

双击项目根目录的 **`start-demo.cmd`**：会检查 `npm`、必要时执行 `npm install`，启动 Vite 并打开浏览器。

### 构建后预览

```bash
npm run build
npm run preview
```

打开 `http://localhost:4173/`。同样**不要**直接双击 `dist/index.html`。

要求 Node.js 18+。项目为纯前端 MVP，打印使用浏览器原生 `window.print()`。

## 多课程：切换与新建

### 切换课程

1. 点击侧栏顶部「当前课程」卡片，或直接点击卡片上的「切换 / 新建课程」。
2. 在弹窗的「内置演示模板」或「自定义课程」中选择目标课程。
3. 点击「载入此模板 / 切换到此课程」。

切换课程会整页重启到 `/outline`，知识点、蓝图、契约、候选题、审查记录与审计日志全部重新初始化，**不同课程的数据不会混用**。这是纯前端 MVP 的有意设计：没有数据库，就用「课程 id + 整页重启」保证课程隔离。

内置模板：

| 课程 | 模板 id | 说明 |
| --- | --- | --- |
| 数据结构 | `DS-2025` | 附录 B 演示模板：8 章 / 56 学时 / 42 个确立知识点 / 47 个候选 / 26 题 / 100 分 / 120 分钟 |
| 操作系统 | `OS-2025` | 6 章 / 46 学时 / 29 个知识点（另有 3 个超纲禁区）/ 26 题 / 100 分 |
| 计算机网络 | `CN-2025` | 6 章 / 46 学时 / 28 个知识点（另有 3 个超纲禁区）/ 26 题 / 100 分 |

> 《数据结构》保留为默认演示模板，附录 B 的章节、学时、题型结构与分值不变；它只是三个内置模板之一。

### 新建自定义课程

1. 打开课程弹窗 →「新建自定义课程」。
2. 填写课程名称、考试名称与说明。
3. 填写章节，每行格式：`章节名 | 学时`。蓝图题量会按学时权重自动分配到各章，教师仍可在蓝图看板微调。
4. 填写知识点，每行格式：`章节名 | 知识点 | 认知层次`（认知层次可选：记忆 / 理解 / 应用 / 分析 / 综合）。
   - 可点击「按章节生成知识点」快速生成占位基线；
   - 留空时每章自动生成“核心概念 / 方法与应用”两个知识点。
5. 配置题型：名称、每题分值、目标题量。题型角色按顺序固定为单选 / 填空 / 简答 / 综合设计，名称与分值可改，满分按「题量 × 分值」自动汇总。
6. 配置考试时长、覆盖率阈值、三维配比带宽、易 / 中 / 难占比与超纲禁区。
7. 点击「创建并载入课程」，系统生成模板、切换当前课程并重启到 `/outline`。

自定义课程保存在浏览器 `localStorage`：

- `papercompile.course.active`：当前课程 id；
- `papercompile.courses.custom`：自定义课程模板数组。

在课程弹窗中可删除自定义课程；也可以在浏览器开发者工具中清空上述两个键恢复默认《数据结构》模板。所有数据仅在本机浏览器内，不写后端、不写数据库。

### 课程模板包含什么

一个课程模板包含：课程名称、考试名称、大纲章节与段落、学时、知识点（含权重 / 认知层次 / 超纲禁区 / 先修关系）、题型定义（名称 / 分值 / 题量 / 建议用时 / 认知层次）、难度目标、覆盖率阈值、允许配比带宽、历史题库种子与演示候选注入配置。

知识点、蓝图、契约、候选题与七道闸门都从当前课程模板读取，因此切换课程后：

- 知识点工作台显示当前课程的知识点基线；
- 蓝图看板显示当前课程的章节 × 题型矩阵；
- 命题契约按当前课程的满分 / 题量 / 题型 / 难度生成；
- 命题 Agent 按当前课程的章节与知识点生成候选；
- 超纲闸门按当前课程的超纲禁区拦截；
- 成卷页的课程名、试卷编号、题型结构、答题区随之变化。

## 八个页面职责

| 步骤 | 页面 | 唯一核心职责 | 关键交互 |
| --- | --- | --- | --- |
| 1 | 01 大纲解析页 | 导入大纲、解析候选知识点、确认生成知识点草稿 | 章节树、段落锚点对照、批量采纳 / 忽略、确认草稿 |
| 2 | 02 知识点工作台 | 审定知识点基线 | 编辑权重 / 认知层次 / 超纲禁区 / 先修关系，保存基线 |
| 3 | 03 蓝图看板 | 配置章节 × 题型 × 分值 × 难度 | 矩阵单元格直接编辑、三维配比偏差、覆盖率、调整建议 |
| 4 | 04 命题契约编辑器 | 配置结构化契约并做可满足性静态检查 | 表单与规则表达式双视图、冲突定位到字段、保存契约 |
| 5 | 05 命题工作区 | 发起多 Agent 命题任务、查看调度队列与拦截记录 | 发起出题、局部重出、失败重试、任务队列、七道闸门结果 |
| 6 | 06 题目审查台 | 教师逐题终审 | 三栏对照（锚点 / 题目 / 证据）、通过 / 改写 / 换题 / 退回、理由必填、七层溯源 |
| 7 | 07 成卷与导出 | 调整题序、版式预览、签发、打印导出 | 学生卷 / 教师卷、二次确认签发、派生新版本、打印 |
| 7 | 08 过程回放 | 时间轴复盘、版本 diff、查看全过程留痕 | 事件筛选、L1~L7、四类快照、同参数重编译、版本 diff |

## 七步闭环与演示路径

| 步骤 | 页面 | 关键动作 | 期望结果 |
| --- | --- | --- | --- |
| 1 | 01 大纲解析页 | 选完整项 → 采纳选中 → 确认生成知识点草稿 | 8 章、56 学时、47 个候选、42 个确立、5 条空要求 |
| 2 | 02 知识点工作台 | 标记超纲禁区、调整认知层次 → 保存基线 | 知识点基线 v1 |
| 3 | 03 蓝图看板 | 核对矩阵 → 下一步 | 26 题 / 100 分 / 0.68 |
| 4 | 04 命题契约编辑器 | 检查并保存契约 v1 → 下一步 | 13 条契约项、可满足性检查通过 |
| 5 | 05 命题工作区 | 发起出题 → 题目审查台 | 41 个候选、入池 39、9 需复核、2 拦截、6 仲裁升级、26 题草案 |
| 6 | 06 题目审查台 | 39 题逐题通过 / 改写；改写需填理由 | 定稿题目集、状态已审、审计日志 |
| 7 | 07 成卷与导出 → 08 过程回放 | A4 预览、学生 / 教师卷、二次确认签发、派生新版本、打印；回放时间轴 | 试卷编号 / 版本页脚、版本快照、L1~L7、四类快照、版本 diff |

顶部状态条依次为 `草稿 → 待审 → 已审 → 已签发 → 已归档`；签发后不可原地修改，只能派生新版本并重新签发。AI 不进入签发链路，签发记录只写教师账号与时间。

### 精简演示步骤

1. **大纲**：打开 `01 大纲解析页`，点击「选完整项」→「采纳选中」→「确认生成知识点草稿」→「前往知识点工作台」。
2. **知识点**：在 `02 知识点工作台` 确认「线索二叉树」「B 树」为超纲禁区，调整「图的遍历」认知层次，点击「保存基线」→「下一步 · 蓝图看板」。
3. **蓝图**：`03 蓝图看板` 核对 26 题 / 100 分 / 0.68；可临时增删题量观察偏差提示，用「回退」恢复，再点「下一步 · 契约编辑器」。
4. **契约**：`04 命题契约编辑器` 检查 13 条契约项，点击「保存契约 v1」→「下一步 · 命题工作区」。
5. **出题**：`05 命题工作区` 点击「发起出题」；完成后核对 41 候选 / 39 入池 / 9 需复核 / 2 拦截 / 6 仲裁升级、26 题 / 100 分 / 120 分钟 / 0.68，再点「题目审查台 →」。
6. **终审**：`06 题目审查台` 处理 39 题。演示改写 4 题：`T-01-A`、`T-06-A`、`T-13-A`、`T-20-A`；每次点击「改写」填写题干与理由，其余逐题「通过」。完成后「成卷与导出 →」。
7. **成卷**：`07 成卷与导出` 切换学生卷 / 教师卷，调整题序，点击「签发」，二次确认并填写理由；签发后题序锁定，可「派生新版本」生成 v1.1，或直接打印。
8. **回放**：`08 过程回放` 筛选 Agent 调用 / 教师操作 / 版本变更；展开任一题的 L1~L7；查看输入 / 参数 / 决策 / 过程四类快照，运行「同参数重编译」，切换 v1 / v1.1 查看版本 diff。

详细演示话术见 [DEMO_SCRIPT.md](DEMO_SCRIPT.md)。

## 核心机制

- **七道闸门**：覆盖、配比、难度、正确性、超纲、重复、格式。不通过的题目不进入候选题池，只写入拦截记录并附失败证据。演示中 `T-14-B`（线索二叉树）与 `T-24-B`（B 树）被超纲闸门拦截。
- **六个 Agent**：规划 Agent 拆任务；命题 Agent 按任务生成；审题 Agent 只看 L1 题目、不接收命题理由；校验 Agent 执行七道闸门；仲裁 Agent 处理命题 / 审题冲突，无法裁决则升级人工；组卷 Agent 负责题序、时间预算与版式装配。
- **七层溯源**：L1 题目、L2 契约、L3 蓝图、L4 知识、L5 大纲、L6 调用、L7 决策；审查台与回放均可展开。
- **审计日志**：教师操作理由、状态变更（操作者 / 时间 / 前后状态 / 理由）、版本快照；回放时间轴统一呈现。
- **四类快照**：输入快照、参数快照、决策快照、过程快照；同参数重编译按考点 / 答案 / 分值判定等价，不要求文字一致。
- **权限**：课程组、主讲教师、审题人、助教四级；助教可提交候选与批注，不可签发；跨课程数据按 `courseId` 隔离。演示账号为李老师（主讲教师）。
- **不自动定稿**：即使全部题目通过校验且审题结论均为通过，系统仍停在「已审」，等待教师签发。

## 数据口径

内置《数据结构》模板对齐说明书附录 B：8 章 / 56 学时 / 42 个确立知识点 / 47 个候选知识点 / 6 条超纲禁区 / 120 道历史题；26 题、100 分、120 分钟；题型 15×2 + 5×2 + 4×5 + 2×20；难度 30/50/20，整卷加权期望 0.68。

操作系统与计算机网络模板按同一套结构生成 26 题 / 100 分，用于验证课程切换、题型自定义、蓝图重算、契约生成、命题调度与成卷导出。自定义课程的满分按「题量 × 分值」自动汇总，不强制 100 分。

## 已知边界

- 大纲解析、模型调用、向量查重、DOCX/PDF 导出均为前端 mock；不接入真实 LLM、后端或数据库。
- 切换课程会重启当前页面并清空未保存会话，这是纯前端 MVP 的课程隔离方式。
- 打印使用浏览器原生打印，版式以 A4 预览为准。
