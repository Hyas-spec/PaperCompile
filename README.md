# 题衡 PaperCompile

面向高校课程组的「大纲 → 标准化试卷」命题编译 MVP：把大纲解析、知识点审定、蓝图、契约、多 Agent 出题审题、教师终审、成卷导出与过程回放串成一条可检查、可追溯、可复现的流水线。

## 启动

```bash
cd papercompile
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`（Vite 默认端口；如被占用以终端输出为准）。

```bash
npm run build    # tsc --noEmit + vite build
npm run preview  # 预览构建产物
```

要求 Node.js 18+。项目为纯前端 MVP，不依赖后端、数据库或 DOCX/PDF 库；打印使用浏览器原生 `window.print()`。

## 七步闭环

| 步骤 | 页面 | 关键动作 | 期望结果 |
| --- | --- | --- | --- |
| 1 | 01 大纲解析页 | 选完整项 → 采纳选中 → 确认生成知识点草稿 | 8 章、56 学时、47 个候选、42 个确立、5 条空要求 |
| 2 | 02 知识点工作台 | 标记超纲禁区、调整认知层次 → 保存基线 | 知识点基线 v1 |
| 3 | 03 蓝图看板 | 调整题型/分值/难度 → 下一步 | 表 B-1 的 26 题 / 100 分 / 0.68 |
| 4 | 04 命题契约编辑器 | 检查并保存契约 v1 → 下一步 | 13 条契约项、可满足性检查 |
| 5 | 05 命题工作区 | 发起出题 → 题目审查台 | 41 个候选、入池 39、9 需复核、2 拦截、6 仲裁升级、26 题草案 |
| 6 | 06 题目审查台 | 39 题逐题通过/改写；改写需填理由 | 定稿题目集、状态已审、审计日志 |
| 7 | 07 成卷与导出 → 08 过程回放 | A4 预览、学生/教师卷、二次确认签发、派生新版本、打印；回放时间轴 | 试卷编号/版本页脚、版本快照、L1~L7、四类快照、版本 diff |

顶部状态条依次为 `草稿 → 待审 → 已审 → 已签发 → 已归档`；顶部同时显示七步编译阶段。签发后不可原地修改，只能派生新版本并重新签发。

## 演示操作步骤（精简版）

1. **大纲**：打开 `01 大纲解析页`，点击「选完整项」→「采纳选中」→「确认生成知识点草稿」→「前往知识点工作台」。
2. **知识点**：在 `02 知识点工作台` 将「线索二叉树」「B 树」设为超纲禁区，将「图的遍历」认知层次由「理解」调为「应用」，点击「保存基线」→「下一步 · 蓝图看板」。
3. **蓝图**：`03 蓝图看板` 核对表 B-1 的 26 题 / 100 分 / 0.68；可临时调整算法题量观察总分/配比提示，用「回退」恢复，再点「下一步 · 契约编辑器」。
4. **契约**：`04 命题契约编辑器` 检查 13 条契约项，点击「保存契约 v1」→「下一步 · 命题工作区」。
5. **出题**：`05 命题工作区` 点击「发起出题」；完成后核对 41 候选 / 39 入池 / 9 需复核 / 2 拦截 / 6 仲裁升级、26 题 / 100 分 / 120 分钟 / 0.68，再点「题目审查台 →」。
6. **终审**：`06 题目审查台` 处理 39 题。演示改写 4 题：`T-01-A`、`T-06-A`、`T-13-A`、`T-20-A`；每次点击「改写」填写题干与理由，其余逐题「通过」。完成后「成卷与导出 →」。
7. **成卷**：`07 成卷与导出` 切换学生卷/教师卷，调整题序，点击「签发」，二次确认并填写理由；签发后题序锁定，可「派生新版本」生成 v1.1，或直接打印。
8. **回放**：`08 过程回放` 筛选 Agent 调用/教师操作/版本变更；展开任一题目的 L1~L7；查看输入/参数/决策/过程四类快照，运行「同参数重编译」，切换 v1/v1.1 查看版本 diff。

详细竞赛演示话术见 [DEMO_SCRIPT.md](DEMO_SCRIPT.md)。

## 核心校验

- **七道闸门**：覆盖、配比、难度、正确性、超纲、重复、格式；不通过不进入候选题池，写入拦截记录并附失败证据。演示中 `T-14-B`（线索二叉树）与 `T-24-B`（B 树）被超纲闸门拦截，不出现在审查列表。
- **七层溯源**：L1 题目、L2 契约、L3 蓝图、L4 知识、L5 大纲、L6 调用、L7 决策；审查台与回放均可展开。
- **审计日志**：教师操作理由、状态变更（操作者/时间/前后状态/理由）、版本快照；回放时间轴统一呈现。
- **四类快照**：输入快照、参数快照、决策快照、过程快照；同参数重编译按考点/答案/分值判定等价，不要求文字一致。
- **权限**：课程组、主讲教师、审题人、助教四级；助教可提交候选与批注，不可签发；跨课程数据按 `courseId` 隔离。演示账号为李老师（主讲教师）。

## 目录

```text
src/
  pages/        01~08 八个主页面与 mock 数据
  agents/       规划/命题/审题/校验/仲裁/组卷、调度器、七道闸门、模型适配器 mock
  store/        试卷状态、知识点、契约、命题、审查、成卷、回放事件、审计、演示会话
  hooks/        usePermission 权限 hook
  data/         附录 B 演示数据
  styles/       全局与各页面样式
```

演示数据对齐说明书附录 B：8 章 / 56 学时 / 42 个确立知识点 / 47 个候选知识点 / 6 条超纲禁区 / 120 道历史题；26 题、100 分、120 分钟；题型 15×2 + 5×2 + 4×5 + 2×20；难度 30/50/20，整卷加权期望 0.68。
