# 截图与录屏资产

> README、技术文档、视频里用的图放这里。提交前只保留最新版本，避免仓库过大。

建议：

- `screenshot-home.png`：首屏/大纲页
- `screenshot-blueprint.png`：蓝图 + 覆盖矩阵
- `screenshot-review.png`：审校台 + 审题证据
- `screenshot-paper.png`：A4 成卷/答案卷
- `demo.gif`：30 秒主线（可选，控制在 5MB 内）
- `reproduce.mp4`：10 分钟复现（如要放仓库，先压缩；正片放提交平台）

原则：

- 不要放带个人隐私/学校真实信息的截图。
- 不要放 P 图/伪造的界面。
- 截图命名与文档引用一致。
- 大文件用外链或压缩，不要把原始录屏塞进 Git。
